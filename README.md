# Programa 1: Parea_perimetro_circulo
programa en pyton para calcular el area de un circulo dado el valor de su radio

## Analisis

### Variables de entrada
- r: radio del circulo
 ### procesamiento
 - a: area del circulo
 - p: perimetro del circulo


 a = \pi*r^2$

 p = 2*\pi*r$
